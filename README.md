# DragonForge one-pager

Static HTML/CSS/JS export of the DragonForge Webflow site. Layout, typography, assets, and interactions are unchanged from the export.

## Run locally

From this directory:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

The page expects a local HTTP server because browsers restrict some video/font behavior over `file://`.
